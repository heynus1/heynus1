## 🛠️ What I Do

I mainly work on autonomous driving software, focusing on planning, control, perception, and ROS-based system integration.

- **Global / Local Path Planning**  
  Designing driving paths based on global maps and local driving conditions.

- **Path Tracking Control**  
  Implementing tracking algorithms such as Pure Pursuit, Stanley, and PID control to follow target paths accurately.

- **Vehicle Control**  
  Developing steering and velocity control logic for stable autonomous driving.

- **Local Path Planning and Obstacle Avoidance**  
  Developing local path planning and obstacle avoidance logic for safe autonomous driving.

- **Sensor-based Perception**  
  Processing LiDAR and camera data for lane detection, obstacle detection, and driving environment recognition.

- **Sensor Fusion**  
  Integrating GPS, IMU, LiDAR, and camera data to improve vehicle localization and driving reliability.

- **Mission-based State Machine Design**  
  Designing ROS-based state machines for mission scenarios such as lane driving, obstacle avoidance, tunnel driving, and parking.

- **ROS 1 / ROS 2 System Integration**  
  Connecting planning, control, perception, and hardware modules into one autonomous driving system.

- **Simulation and Testing**  
  Testing autonomous driving algorithms in simulation environments before applying them to real platforms.

- **Debugging and Performance Improvement**  
  Analyzing driving logs, sensor data, and control outputs to improve system stability and driving performance.
